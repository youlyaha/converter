# Тест-кейсы

Документ содержит сценарии проверки программы перевода целого десятичного числа в систему счисления с основанием от 2 до 16. Каждый тест-кейс проверяет один сценарий.

**Результаты заполнены по выполненным автоматическим проверкам функций и модульных тестов.** Для тест-кейсов, описывающих действия в графическом интерфейсе, проверена соответствующая логика на уровне функций/файлов; ручной проход по окнам и кнопкам GUI не выполнялся в этой среде.

**Предусловия:** Программа запущена. Открыта форма конвертера.

**Шаги:**
1. В поле десятичного числа ввести `10`.
2. В поле основания системы счисления ввести `2`.
3. Нажать кнопку перевода.

**Ожидаемый результат:** Программа отображает результат `1010`.

**Фактический результат:** Автоматическая проверка `decimal_to_base(10, 2)` вернула `1010`; результат соответствует ожидаемому. Проверка выполнена на уровне функции, графический интерфейс вручную не нажимался.

**Статус:** Passed
