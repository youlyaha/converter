# 🔢 Конвертер систем счисления

🇷🇺 Русский · [🇬🇧 English](README.en.md)

## Описание
Приложение Python/Tkinter переводит целые десятичные числа в системы счисления с основаниями 2–16. Поддерживает ввод из интерфейса и TXT, сохранение результата, резервное копирование/восстановление внутренней JSON-таблицы и журналирование.

## Возможности
- Перевод положительных и отрицательных целых чисел и нуля.
- Основания 2–16; для значений цифр выше 9 используются `A–F`.
- Загрузка данных и сохранение результата в TXT.
- Создание и восстановление резервной копии JSON-таблицы.
- Запись событий в `logs/app.log` через отдельный модуль `logger.py`.
- Графический и дополнительный консольный режим.

## Требования
Python 3.10+. Используются стандартные библиотеки Python; внешние зависимости не нужны.

## Запуск
```bash
python converter_tkinter.py
```
Консольный режим:
```bash
python converter_tkinter.py --console
```

## Использование
Введите целое десятичное число, выберите основание 2–16 и нажмите «Преобразовать». TXT-файл может содержать число и необязательное основание, например `255 16`.

## Резервное копирование
Кнопка «Создать резервную копию» копирует `data/encoding_mapping.json` в `backups/`. Для восстановления выберите JSON-копию и подтвердите замену. Файл проверяется на корректность JSON-объекта. Таблица является внутренней таблицей приложения, а не системной таблицей кодировок Windows.

## Журналирование
Журнал `logs/app.log` создаётся автоматически. Записываются запуск/закрытие, преобразования, ошибки, файловые операции и резервное копирование.
